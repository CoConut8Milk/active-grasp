# Active-Grasp：主动视角选择与视觉推抓的 ROS2 仿真项目

一个可以在 **纯仿真** 里跑通的桌面杂乱场景抓取系统：机器人在 ROS2 + Gazebo
中观察杂乱物体，学会**主动选择下一个观察视角**，再用「推 + 抓」把桌面清理干净。

此项目：它有明确的科学问题、可复现的基线与消融实验、完整的
工程闭环，全部不依赖任何真实硬件。

> 研究问题：在视觉推抓（VPG）框架上加入**不确定性驱动的主动视角选择
> (Next-Best-View)**，能否系统性地提升杂乱场景的抓取与清理效率？

## 一句话方法

机器人的腕部相机从「默认视角」看到的场景存在遮挡。感知模块把多视角 RGB-D
融合成 **高度图 + 不确定度图**；DDQN 智能体在三种动作间选择：

1. **抓**：在高度图的某个网格点做竖直抓取，成功后放进回收盒；
2. **推**：把某个物体朝 8 个方向之一水平推开，制造抓取空间；
3. **看**：把相机移到 4 个备用视角之一再观测，用「信息增益」降低不确定度。

「看」是有代价的动作（花时间、还可能没收益），所以智能体必须学会**什么时候
值得看、该从哪个角度看**——这正是具身智能研究里 active perception 的核心问题。

## 系统架构

```
                  ┌────────────────────────────┐
                  │   Gazebo Classic 仿真世界    │
                  │  6-DOF 臂 + 二指爪 + 深度相机 │
                  └──────────────┬─────────────┘
                                 │ RGB-D 流 / joint states
                  ┌──────────────▼─────────────┐
                  │  ag_perception（感知）       │
                  │  多视角融合 → 高度图          │
                  │  → 不确定度图（空洞/陈旧/边缘）│
                  └──────┬─────────────┬───────┘
                         │ Observe 服务 │ Grasp/Push/MoveView 服务
            ┌────────────▼──┐      ┌───▼──────────────┐
            │  ag_agent      │      │  ag_execution    │
            │  DDQN / 基线    │◄────►│  数值IK + 运动原语 │
            │  奖励/课程学习   │      └──────────────────┘
            └───────────────┘
```

## 特性

- 零硬件、零网格文件依赖：机械臂完全由 URDF 原生几何体构成，克隆即用。
- 手写 FK/数值 IK（scipy），运动学从 URDF 运行时解析，模型与仿真永远一致。
- 有原创成分的感知：多视角高度图融合 + 三因子不确定度图
  （空洞 / 信息年龄 / 遮挡边缘），相机镜像自动标定。
- VPG 风格的像素级 Q 网络：抓取 Q 图 + 8 方向推动 Q 图 + 视角 Q 头，DDQN 训练。
- 完整研究管线：课程学习、域随机化、三个基线（贪心 / 随机 / 无视角消融）、
  多随机种子评估、CSV 指标与学习曲线。

## 目录结构

```
active-grasp/
├── config/                # 实验配置（策略/场景/API，唯一需要改的入口）
├── src/
│   ├── ag_interfaces/     # 自定义 ROS2 服务接口

│   ├── ag_gazebo/         # 桌面世界 + 程序化物体生成器
│   ├── ag_perception/     # 高度图/不确定度融合（核心算法）
│   ├── ag_execution/      # FK/IK + 抓/推/看运动原语
│   ├── ag_agent/          # DDQN 智能体、环境封装、训练/评估
│   └── ag_bringup/        # 顶层 launch
├── tests/                 # 35 个纯 Python 单元测试（可在任何机器跑）

├── docker/                # Humble + Gazebo 容器
└── docs/                  # 中文教程与讲解（见下文索引）
```

## 快速开始

环境要求：Ubuntu 22.04（推荐 WSL2，Windows 10/11 均可，无需显卡）。

```bash
# 1. 安装系统依赖（ROS2 Humble + Gazebo Classic，一次性）
bash scripts/setup_wsl2.sh

# 2. 编译
bash scripts/build.sh

# 3. 跑图形界面演示（贪心基线，先验证整条流水线）
bash scripts/run_demo.sh

# 4. 无头快速训练（约几百个回合，CPU 可跑）
bash scripts/train.sh

# 5. 评估训练好的策略
bash scripts/evaluate.sh checkpoints/agent_final.pth

# 6. 用新的 API 模型（任意 OpenAI 兼容端点）跑策略实验
cp .env.example .env       # 填入 AGENT_API_KEY
source .env
bash scripts/check_api.sh
bash scripts/run_vlm_demo.sh
```

更细的步骤、每一步的预期输出和验收标准见
[docs/03_快速跑通流程.md](docs/03_快速跑通流程.md)。
